## 📌 Profile Overview

I am an engineering student in **Electronics and Communication Systems** (*Systèmes Connectés*), focused on the convergence of physical hardware, embedded firmware, communication networks, and intelligent software layers.

My technical objective is to engineer reliable solutions combining electronic circuit design, microcontroller platforms, sensor acquisition, wireless telemetry, software automation, and data processing.

* **Embedded Hardware & IoT:** Firmware development (STM32, ESP32, Arduino), multi-sensor interfacing, hardware communication protocols (UART, SPI, I2C), and long-range telemetry (LoRa).
* **Software Quality & Automation:** Enterprise test automation, Page Object Model (POM) architecture, API authentication mechanisms, and CI/CD pipelines (Playwright, Pytest, Postman, GitHub Actions).
* **Applied Machine Learning & Control:** Dynamic system modeling, predictive classification models for sensor data, and reinforcement learning simulations (Gymnasium, Stable-Baselines3, PPO).
* **Industrial Simulation:** Sequential logic modeling and finite state machine (FSM) architectures using LabVIEW.
