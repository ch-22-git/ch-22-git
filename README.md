## 🚀 Featured Projects

### [AquaSense – IoT Water Quality Monitoring System](https://github.com/ch-22-git/AquaSense-IoT-Water-Quality-Monitoring)
> **Multidisciplinary IoT solution combining embedded sensing, wireless telemetry, a web dashboard, and applied artificial intelligence.**

- **Sensor Data Acquisition:** Continuous measurement and acquisition of critical water quality metrics using dedicated physical sensors.
- **Wireless Node Communication:** Data exchange configured between two CM32 microcontroller boards, utilizing integrated LoRa communication for telemetry.
- **Real-Time Visualization:** Interactive web dashboard providing live monitoring of incoming water quality measurements.
- **Intelligent Classification Agent:** Machine learning agent integrated into the pipeline to evaluate parameters and predict whether the water is safe or unsafe.
- **Multi-Domain Synergy:** Demonstrates seamless end-to-end integration across hardware design, wireless protocols, cloud software, and applied AI.

**Technologies:** `IoT` • `CM32` • `LoRa Wireless` • `Sensor Integration` • `Web Dashboard` • `Machine Learning`
